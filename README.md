## 🎨 Visual Design Direction & Aesthetics

* **Theme:** Premium dark-first developer aesthetic.
* **Palette:** Deep Obsidian Base (`#06080E`, `#0A0E17`), Slate Card Surfaces (`#0E1420`), Electric Blue primary accent (`#3B82F6`), Cyan secondary accent (`#06B6D4`), Emerald green validation highlights (`#34D399`).
* **Typography:** Plus Jakarta Sans for interface hierarchy paired with JetBrains Mono for technical telemetry and code badges.
* **Micro-Interactions & Visual FX:**
  * Interactive mouse spotlight glow following cursor.
  * Custom lerping dual-element desktop cursor with hover states.
  * 60fps ambient particle canvas with dynamic node distance connections.
  * 3D perspective tilt on interactive cards.
  * Dynamic scroll progress indicator.
  * Sliding active-section navbar indicator synchronized via IntersectionObserver.
  * Accessible modal dialogs with escape key and backdrop dismissal.
